# Remix of Pharma Gateway

Using this portfolio make a creative pharmaceutical export website for medicines (injectables) so that buyers from the Middle East and the Philippines can explore products and submit inquiries for their medicine requirements.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://global-med-express.lovable.app
